# Formats d'import acceptés

Placez ici vos exports CSV/XLSX de backlinks concurrents.

## Ahrefs
Menu: Site Explorer → Backlinks → Export CSV
Colonnes détectées: `Referring page URL`, `Domain Rating`, `Anchor`, `Dofollow`

## SEMrush
Menu: Backlink Analytics → Backlinks → Export
Colonnes détectées: `Source URL`, `Authority Score`, `Anchor Text`

## Majestic
Menu: Site Explorer → Backlinks → Export
Colonnes détectées: `SourceURL`, `TrustFlow`, `AnchorText`

## Moz
Menu: Link Explorer → Inbound Links → Export
Colonnes détectées: `Linking Page URL`, `Domain Authority`

## Format générique
Si votre outil n'est pas listé, assurez-vous d'avoir au minimum:
- Une colonne URL source (la page qui fait le lien)
- Idéalement: DA/DR, anchor text, dofollow/nofollow
